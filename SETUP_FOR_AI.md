# Setting up the PixelLab game-art skill - instructions for the AI assistant

This repository holds two versions of the same skill:
- You are **Claude Code** → go into `claude-code/` and follow `claude-code/SETUP_FOR_AI.md`.
- You are any other agent (Codex, Gemini CLI, Cursor, VS Code / Copilot, OpenCode, …) → go into
  `any-agent/` and follow `any-agent/SETUP_FOR_AI.md`.

Run the installer from inside that folder. Ask the user only for what you can't do yourself, and
never ask them to paste their PixelLab token into the chat.
